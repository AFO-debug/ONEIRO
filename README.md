# ONEIRO

Psychological survival horror game inspired by dreams, identity, and the fear of becoming human.

---

## Overview

ONEIRO is a narrative-driven psychological survival horror game inspired by classic fixed-camera horror titles and modern atmospheric storytelling.

The game follows an unknown entity trapped inside a dream-like experiment where fragmented worlds, symbolic creatures, and distorted memories slowly shape it into something human.

Each area represents aspects of humanity such as emotion, grief, identity, fear, and consciousness.

---

## Main Inspirations

- Silent Hill
- Signalis
- Alan Wake 2
- Alice: Madness Returns
- Undertale

---

## Core Pillars

### Psychological Horror
The horror is focused on atmosphere, symbolism, emotional discomfort, and surrealism rather than constant jumpscares.

### Dreamlike Exploration
Levels behave like dreams:
- impossible spaces
- shifting environments
- symbolic events
- fragmented memories

### Fixed Cinematic Cameras
Inspired by classic survival horror games, using fixed camera angles combined with modern movement controls.

### Symbolic Creatures
Enemies are manifestations of emotions, fears, memories, and failed humanity.

---

## Artistic Direction

The visual style combines:
- retro low-poly aesthetics
- PS1-inspired survival horror visuals
- industrial and brutalist architecture
- surreal floral imagery
- analog horror influences

Main visual references:
- dark shadows
- heavy atmosphere
- limited color palettes
- visual noise and grain
- red floral symbolism
